# ROE Fighter 游戏说明

用 Rise of Eros（ROE）等游戏的角色模型做的 3D 格斗游戏：一对一，三局两胜，可以横移绕着对手转，
每个角色四个普通攻击、三个技能。ROE 角色的三个技能就是她在 ROE 里的三个战斗技能，特效、音效、语音都是游戏原版的。

<!-- 图: fight.jpg | 比赛画面：上面是两人的体力条和回合计时，下面是能量槽 -->

## 1. 开始游戏

- 双击 `out\ROEFighter\ROEFighter.exe`。整个 `ROEFighter` 文件夹要一起拷（约 2 GB），只拷 exe 运行不了。
- 窗口 1600×900，可以拉大。
- 一开始是选人界面。默认你是 1P，电脑是 2P。

## 2. 选人

<!-- 图: select.jpg | 选人界面：中间两人是当前选中的角色，下面一排是全部角色的卡片 -->

| 操作 | 1P | 2P |
|---|---|---|
| 换卡片 | A、D（或手柄摇杆） | ←、→ |
| 确认 | J、回车、空格（手柄 0 号键） | 小键盘 1、小键盘回车 |
| 退回 | K、Esc（手柄 1 号键） | 小键盘 2 |

- 只有 1P 是人时，先选自己的角色，再替电脑选。
- 卡片上的角色会转过来对着镜头；ROE 角色确认后会放她在 ROE 里的展示动作和台词。
- 比赛结束后按回车回到选人界面，上一场的两人还选着，确认两次就是再来一场。比赛中按 F7 也能随时回来。

## 3. 比赛规则

- 每局 60 秒，体力 1000，先赢两局的获胜。
- 体力打光就是 K.O.；时间到时体力多的一方赢这一局，一样多算平局。
- **能量槽**（屏幕下方，满了显示 MAX）：
  - 普通攻击打中对手就涨（A 到 D 大约涨 5、6、7、8），被挡住涨一半；
  - 技能 1、技能 2 每打中一下涨 4；
  - 超必杀要用掉满满一槽；
  - 能量槽跨局保留，开新比赛才清零。

## 4. 按键

<!-- 图: keys.png | 键盘：左手 WASD 管移动，右手 J K U I 是四个普通攻击，数字 1 2 3 是三个技能 -->

| 操作 | 1P 键盘 | 2P 键盘 | 手柄（1P） |
|---|---|---|---|
| 左右移动 | A、D | ←、→ | 摇杆或十字键 左右 |
| 防御 | 按住远离对手的方向 | 同左 | 同左 |
| 侧步（往画面里 / 往画面外） | W、S | ↑、↓ | 摇杆或十字键 上下 |
| 普通攻击 A、B、C、D | J、K、U、I | 小键盘 1、2、4、5 | 0、1、2、3 号键 |
| 技能 1、技能 2、超必杀 | 1、2、3（或 L、O、P） | 小键盘 3、6、9 | LB（4 号）、RB（5 号）、6 号键 |

屏幕最下面一行也写着这些按键。

### 移动和防御

- **方向按屏幕算**：朝着对手那边按是前进，反方向是后退。开局你在左边、电脑在右边，所以 D 是前进、A 是后退。
- **防御**：按住后退不放就是防御，普通攻击和技能的第一下都能挡。
- **侧步**（W / S）：绕着对手转。出拳、踢腿时朝向是锁住的，侧步能躲开直线攻击。两人绕到换了边以后，方向跟着反过来，还是"朝对手按 = 前进"。
- 没有跳跃和下蹲。

### 普通攻击（J K U I）

- 四个攻击大致从轻到重，伤害 40、60、80、95，越重越慢、推得越远。有的重招会把对手击倒（Inase、Kart 的 D）。
- **连招**：打中或被挡住以后，在招式的后半段可以接着出下一招。
- 每个角色的四招不一样，见第 6 节。

### 技能（1 2 3）

<!-- 图: skill.jpg | INASE 放技能：特效、音效、语音都是游戏原版的 -->

- **技能 1、技能 2** 不要能量；**超必杀** 要满一槽，最后一下把对手击倒。伤害分别是 150、190、360，按游戏里的比例分几下打出。
- **第一下决定结果**：对手按住后退就是挡住（只掉一成）；对手不在打击范围内就打空；否则打中。打中或挡住以后，对手被锁住直到技能放完（游戏里就是这么演的）。
- 有的技能冲到对手面前打，有的原地远程放，能打到游戏里敌人站的那一排那么远。
- 对手离得太远时按了没反应：技能 1、2 要在 6 米以内，超必杀 7 米以内，先走近再放。
- 也能搓招：↓↘→ + J 或 U 是技能 1，↓↙← + J 或 U 是技能 2，↓↘→↓↘→ + J 或 U 是超必杀（→ 指朝着对手的方向，↓ 是 S）。

### 爆衣

- 超必杀打中、或者被 K.O.，衣服会掉一段；决胜局的 K.O. 把剩下的全部打掉。
- F6 开关爆衣，关掉时衣服立刻全部穿回去。

## 5. 功能键

| 键 | 作用 |
|---|---|
| F1 / F2 | 让电脑接管 1P / 2P（再按一次还给人）。两边都交给电脑就是看电脑对打；关掉 2P 的电脑就是两人对战 |
| F3 | 换动作包：用动作包招式的角色换一套普通攻击和走路（比赛重新开始） |
| F4 | 换物理方案：头发、裙子、胸怎么晃（比赛重新开始），见第 7 节 |
| F5 | 裙子：自然下垂 / 跟着腿走 |
| F6 | 爆衣开 / 关 |
| F7 | 回选人界面 |
| F8 | 镜头：避开场景（默认） / 旧镜头 |

换了设置以后，计时器下面会显示几秒当前的设置（动作包、物理、裙子、爆衣、镜头）。

## 7. 物理方案（F4）

| 方案 | 说明 |
|---|---|
| auto（默认） | 每个角色用最适合她的：DOA6 角色用 DOA6 自己的物理，Fiona 用 Vindictus 的，Eve 用剑星的，Inase 用 Magica Cloth 2，Luf 用 swing，其他用骨骼布料 |
| magica_style | 骨骼布料（照 Magica Cloth 2 的做法） |
| swing | 骨骼布料，裙子照游戏手 K 的样子甩 |
| doa6 / doa6_breasts / doa5lr_style | DOA6 的物理 / 只有胸用 DOA6 / DOA5LR 式弹簧网 |
| kawaii / stellar | Vindictus 的 KawaiiPhysics / 剑星的物理 |
| legacy | 10-02 的旧版骨骼布料 |
| off | 不模拟，头发裙子保持站姿的关键帧 |
| magica / magica_full | Magica Cloth 2（同样的骨链） / Magica Cloth 2 全部交给它的预设 |
| roe | ROE 自己的：有关键帧时用关键帧，动起来用游戏自己的 Magica Cloth 2 参数 |

ROE 角色放技能、开场、胜利动作时，裙子和头发用游戏原版的手 K；站在游戏站姿里（目前是 LUF 的站架）时也一样。
例外：magica_full 在这些时候也模拟（INASE 默认就是它），GODDESS LUF 的飘带一直在模拟。

## 8. 电脑对手

- 电脑每 0.1–0.25 秒想一次：保持距离，按距离挑招，看到你出招时有一定几率防御或侧步，偶尔放技能，满槽就放超必杀。
- 想看电脑对打：在比赛里按 F1，让 1P 也交给电脑。

## 9. 启动参数（可选）

在 exe 的快捷方式"目标"后面加上，或在命令行里运行：

| 参数 | 作用 |
|---|---|
| `-roeP1 g04 -roeP2 a08` | 直接选好两个角色（角色代号见下） |
| `-roeSelect 0` | 跳过选人界面，直接开打 |
| `-roeBurst 0` | 爆衣关着启动 |
| `-roeCloth roe` | 用某个物理方案启动（名字见第 7 节） |
| `-roeCamAvoid 0` | 用旧镜头启动 |

角色代号：a08 INASE、g04 LUF、b10 KART、g05 GODDESS LUF、m02 AMANO、b14 CRANE KART、b14_outfit1 PINK CRANE KART、kas KASUMI、kas011 KASUMI 海盗裙、mai MAI、fio005 FIONA、eve09 EVE、eve37 EVE 百褶裙、eve_nikke06 EVE 粉色紧身衣、raven RAVEN。

例：`ROEFighter.exe -roeP1 g04 -roeP2 a08 -roeSelect 0`

## 10. 常见问题

- **按 3 没反应**：能量槽没满（没显示 MAX），或者离对手超过 7 米。
- **按 1、2 没反应**：离对手超过 6 米，先走近。
- **走反了**：方向是按屏幕算的，朝对手那边按才是前进；绕到对面以后要反过来按。
- **只拷了 exe 打不开**：要拷整个 `ROEFighter` 文件夹。

素材来自商业游戏，只供自己玩，不要发布或上传。
