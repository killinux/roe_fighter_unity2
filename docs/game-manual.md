# ROE Fighter 2 游戏说明

用 Rise of Eros（ROE）等游戏的角色模型做的**横版格斗游戏**，玩法照拳皇（The King of Fighters）：两人站在同一条线上面对面打，
镜头从侧面拍；三人一队轮番上场（也可以单挑三局两胜）；能跳、能蹲、按住后退防御、搓招放技能，能量槽分三格。
每个角色四个站立普通攻击是她自己游戏里的招式，三个技能就是她在原游戏里的三个战斗技能，特效、音效、语音都是原版的；
蹲着的和跳起来的普通攻击、吹飞、投技、防御姿势和各种受击倒地动作全部角色共用一套（见第 4 节）。

## 1. 开始游戏

- 双击 `out\ROEFighter2\ROEFighter2.exe`。整个 `ROEFighter2` 文件夹要一起拷（约 2 GB），只拷 exe 运行不了。
- 窗口 1600×900，可以拉大。
- 一开始是选人界面。默认你是 1P，电脑是 2P；默认三人组队。

## 2. 选人（组队）

<!-- 图: select.jpg | 选人界面：中间两人是当前亮着的卡片上的角色，下面一排是全部角色的卡片，两边列着各队已选的人 -->

| 操作 | 1P | 2P |
|---|---|---|
| 换卡片 | A、D（或手柄摇杆） | ←、→ |
| 把卡片上的人加进队里（按顺序） | J、回车、空格（手柄 0 号键） | 小键盘 1、小键盘回车 |
| 退掉最后选的一个 | K、Esc（手柄 1 号键） | 小键盘 2 |

- 一队三人，按选的顺序出场；同一队里不能选两个一样的，两队可以选同一个人（会复制一份）。
- 只有 1P 是人时，先选满自己的三个，再替电脑选三个。
- 卡片上的角色会转过来对着镜头；ROE 角色加进队里时会放她在 ROE 里的展示动作和台词。
- **F8** 在"三人组队"和"单挑"之间切换（回到选人界面）。单挑就是以前的玩法：一人一边，三局两胜。
- 比赛结束后按回车回到选人界面重新选。比赛中按 F7 也能随时回来。

## 3. 比赛规则

- 每局 60 秒，体力 1000。
- **组队赛**：每局双方各上一人，被打倒（K.O.）的一方换下一个人上场；赢的人留在场上，体力不回满，只恢复一点（8% 加上剩余时间的份额，最多再 12%）。
  一队三个人全部倒下就输了。时间到时体力少的一方算输；一样多两边都换人。
- **单挑**：先赢两局的获胜，每局体力重置。
- **能量槽**（屏幕下方，一条正在积的槽，上面三个格子是存下的）：
  - 普通攻击打中对手就涨（A 到 D 大约涨 5、6、7、8），被挡住涨一半；吹飞涨 8；技能 1、技能 2 每打中一下涨 4；投技成功涨 8；挨打也涨 3；
  - 涨满 100 存成一格，最多存三格（显示 MAX）；
  - 超必杀要用掉一格；
  - 留在场上的人能量跟着她，新上场的人从零开始。

### 移动、跳和防御

- **方向按屏幕算**：朝着对手那边按是前进，反方向是后退。开局你在左边、电脑在右边，所以 D 是前进、A 是后退。跳过对手头顶换了边以后，方向跟着反过来。
- **跳**：W 点一下是小跳（低、快），按住是大跳；按着左右跳就是前跳 / 后跳；跑着跳跳得更远。先蹲一下（S）再跳是超级跳（更高更远），蹲一下再点一下是加速小跳。
  空中按攻击键就是跳跃攻击，一跳只能打一下；落地有几帧不能动。
- **防御**：按住后退就是站立防御，能挡住中段和跳跃攻击；按住后下是蹲防，能挡住中段和下段。
  - **下段**（蹲 B、蹲 D 扫腿，以及有的角色标成下段的招）站着挡不住，要蹲防；
  - **跳跃攻击**是上段，蹲着挡不住，要站着挡；
  - 技能的第一下按住后退就能挡（只掉一成）；投技挡不住。
- **跑**和**后撤步**是双击方向。后撤步开头几帧无敌。
- **A+B 回避**：往前滚一段，滚的过程中打不到（最后一小段除外），能滚到对手背后。

### 普通攻击

- **站立 A B C D**（J K U I）：每个角色不一样，见第 6 节。伤害大致 40、60、80、95，越重越慢、推得越远。有的重招会把对手击倒。
- **蹲着的 A B C D**（按住 S 再按攻击，全角色一样）：蹲轻拳（35）、蹲轻脚（45，下段）、蹲重拳（70）、扫腿（80，下段，击倒）。
- **跳跃攻击**（空中按攻击，全角色一样）：空中轻拳（40）、轻脚（50）、重拳（70）、重脚（80），都是上段。
- **C+D 吹飞**（Y）：75 伤害，把对手打飞出去倒地，被挡住的话自己的收招很慢。
- **投技**（贴身 + 前或后 + U）：抓住对手摔出去，110 伤害，挡不住；对手在空中、倒地或正在出招时抓不到。
- **连招**：打中或被挡住以后，在招式的后半段可以接着出下一招。对手被打到空中后还能再追打两下（之后她落地前就打不到了）。
- 站着出拳打头的招（比如刺拳）会从蹲着的对手头上掠过去，打不中。

### 技能（1 2 3）

<!-- 图: skill.jpg | INASE 放技能：特效、音效、语音都是游戏原版的 -->

- **技能 1、技能 2** 不要能量；**超必杀** 要一格能量，最后一下把对手击倒。伤害分别是 150、190、360，按游戏里的比例分几下打出。
- **第一下决定结果**：对手按住后退就是挡住（只掉一成）；对手不在打击范围内就打空；否则打中。打中或挡住以后，对手被锁住直到技能放完（游戏里就是这么演的）。
- 有的技能冲到对手面前打，有的原地放，能打到游戏里敌人站的那一排那么远。
- **远程技能**：INASE 的技能 2（沿光线甩出飞剑）、KART（红衣）的技能 1、2（双枪）、AMANO 的超必杀在 ROE 里本来就是远程的，这里全场任何距离都打得到；
  对手跳在空中时打空（像拳皇里跳过气功波）。
- 对手离得太远时按了没反应：技能 1、2 要在 6 米以内，超必杀 7 米以内，先走近再放（远程技能不限）。
- 也能搓招：↓↘→ + J 或 U 是技能 1，↓↙← + J 或 U 是技能 2，↓↘→↓↘→ + J 或 U 是超必杀（→ 指朝着对手的方向，↓ 是 S）。
- 技能只能站在地上放。

### 爆衣

- 超必杀打中、C+D 吹飞打中、被投技摔出去、被 K.O.，衣服各掉一段（每人四段）；决定比赛的那个 K.O. 把剩下的全部打掉。
- 掉了就一整场比赛不回来（组队赛里留在场上的人接着打）。
- F6 开关爆衣，关掉时衣服立刻全部穿回去。

## 5. 功能键

| 键 | 作用 |
|---|---|
| F1 / F2 | 让电脑接管 1P / 2P（再按一次还给人）。两边都交给电脑就是看电脑对打；关掉 2P 的电脑就是两人对战 |
| F3 | 换动作包：用动作包招式的角色换一套站立普通攻击和走路（比赛重新开始） |
| F4 | 换物理方案：头发、裙子、胸怎么晃（比赛重新开始），见第 7 节 |
| F5 | 裙子：自然下垂 / 跟着腿走 |
| F6 | 爆衣开 / 关 |
| F7 | 回选人界面 |
| F8 | 三人组队 / 单挑（回选人界面） |

换了设置以后，计时器下面会显示几秒当前的设置（模式、动作包、物理、裙子、爆衣）。

## 7. 物理方案（F4）

| 方案 | 说明 |
|---|---|
| auto（默认） | 每个角色用最适合她的：DOA6 角色用 DOA6 自己的物理，Fiona 用 Vindictus 的，Eve 用剑星的，Inase 用 Magica Cloth 2，Luf 用 swing，其他用骨骼布料 |
| magica_style | 骨骼布料（照 Magica Cloth 2 的做法） |
| swing | 骨骼布料，裙子照游戏手 K 的样子甩 |
| doa6 / doa6_breasts / doa5lr_style | DOA6 的物理 / 只有胸用 DOA6 / DOA5LR 式弹簧网 |
| kawaii / stellar | Vindictus 的 KawaiiPhysics / 剑星的物理 |
| legacy | 10-02 的旧版骨骼布料 |
| off | 不模拟，头发裙子保持站姿的关键帧 |
| magica / magica_full | Magica Cloth 2（同样的骨链） / Magica Cloth 2 全部交给它的预设 |
| roe | ROE 自己的：有关键帧时用关键帧，动起来用游戏自己的 Magica Cloth 2 参数 |

ROE 角色放技能、开场、胜利动作时，裙子和头发用游戏原版的手 K；站在游戏站姿里（LUF、INASE 的站架）时也一样。
例外：magica_full 在这些时候也模拟（INASE 默认就是它），GODDESS LUF 的飘带一直在模拟。

## 8. 电脑对手

- 电脑每 0.1–0.25 秒想一次：保持距离，按距离挑站着的或蹲着的招，贴身时会投，看到你出招时有一定几率防御（下段来了就蹲防）、滚过去或后撤，
  看到你跳过来会用重拳重脚迎击，离得远会跑过来或跳过来，偶尔放技能，有一格能量就可能放超必杀。
- 想看电脑对打：在比赛里按 F1，让 1P 也交给电脑。

在 exe 的快捷方式"目标"后面加上，或在命令行里运行：

## 10. 常见问题

- **按 3 没反应**：没存下一格能量，或者离对手超过 7 米。
- **按 1、2 没反应**：离对手超过 6 米，先走近；或者正在空中。
- **走反了**：方向是按屏幕算的，朝对手那边按才是前进；跳到对面以后要反过来按。
- **防不住**：下段要蹲防（后 + 下），跳跃攻击要站着防；投技防不住，可以跳开或后撤步。
- **总是小跳**：W 要按住不放才是大跳。
- **只拷了 exe 打不开**：要拷整个 `ROEFighter2` 文件夹。

素材来自商业游戏，只供自己玩，不要发布或上传。
